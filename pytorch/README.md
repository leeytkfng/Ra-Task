# PyTorch 직접 구현 공간

TensorFlow 원본의 수식과 텐서 흐름을 설명할 수 있게 된 뒤, 같은 Lab 번호의
PyTorch 파일을 이 폴더에 직접 작성합니다.

`lab-02-1-linear_regression.py`는 직접 작성한 첫 번째 실행 코드입니다.
`lab-03_minimizing_cost.py`에서는 Cost Function 시각화, 수동 Gradient Descent,
PyTorch SGD 비교, Learning Rate 실험을 이어서 구현합니다.

앞으로 만드는 연습장도 같은 형식을 사용합니다.

- TensorFlow 원본 줄과 PyTorch 대응 관계
- 직접 구현할 범위와 확인 질문을 TODO로 제공
- 수식과 Tensor shape 설명
- 중간 확인 질문
- 실행 후 보고서에 기록할 항목

명시적으로 완성을 요청하지 않는 한 사용자가 작성한 코드나 TODO를 대신 채우지
않습니다.
